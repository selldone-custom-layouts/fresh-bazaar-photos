# Fresh Bazaar — product & category photos

Real photographs of fruit, vegetables and herbs, cut out and placed on one shared studio backdrop
(warm cream sweep, soft contact shadows) so a whole catalog reads as a single shoot. Made for the
Fresh Bazaar demo shop on Selldone.

- `products/<product>-main.jpg` — hero shot (often whole + cut)
- `products/<product>-g1.jpg … g3.jpg` — gallery shots (single piece, cross-section, top view)
- `categories/<category>.jpg` — category still lifes built from the same cutouts

All images are 1600 × 1600 JPEG.
